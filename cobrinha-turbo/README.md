# Cobrinha Turbo

Jogo da cobrinha em HTML, CSS e JavaScript puro, tudo em um arquivo só. A diferença para o clássico é que a cobra acelera a cada fruta.

Para jogar é só abrir o `index.html` no navegador.

## Controles

- Setas ou WASD para mover (no celular, deslizando o dedo)
- Espaço ou Enter para pausar

## Regras

- Fruta vermelha: 1 ponto, e a cobra fica mais rápida
- A cada 5 frutas aparece uma especial, que some em 7 segundos e vale 3 pontos
  - azul: atravessa as paredes por 8s
  - roxa: câmera lenta por 6s
- O recorde fica salvo no navegador (localStorage)
